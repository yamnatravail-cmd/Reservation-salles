# Reservation-salles

Application web de réservation de salles.

## Description

Ce projet permet de gérer la réservation des salles.

## Technologies utilisées

- Laravel
- PHP
- JavaScript
- Node.js / npm

## Installation

1. Cloner le projet.
2. Installer les dépendances PHP :

   ```bash
   composer install
   ```

3. Installer les dépendances JavaScript :

   ```bash
   npm install
   ```

4. Copier le fichier d'environnement :

   ```bash
   cp .env.example .env
   ```

5. Générer la clé Laravel :

   ```bash
   php artisan key:generate
   ```

6. Lancer l'application :

   ```bash
   php artisan serve
   ```

## Développement frontend

Pour compiler les ressources frontend :

```bash
npm run dev
```
